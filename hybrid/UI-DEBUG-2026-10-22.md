# Control Centre debug report — 22 October 2026

Core implementation: `665026a`; native routing update `3be5dc2` uses version code 6 / `1.2.1-hybrid`.

## Symptom and confirmed causes

1. Returning from StandBy left arrow keys apparently stuck. The controls panel was hidden on pause and its descendant focus was lost; Android then selected the background or the first child. `ControlCentreActivity.java` now saves the selected control, restores it after resume/window focus and links all D-pad edges explicitly.
2. Opening from the gear briefly clipped the background blur. `HomeApps.java` applied an app-launch scale-up animation to the entire fullscreen controls activity. It now opens without that window animation; only the compact panel scales, following the original tvOS easing and timing.
3. Captions and several icon drawings were off-centre. `ControlCentreActivity.java` now centres captions within their cells, permits focus growth and reserves a top gutter. Ten `hybrid_ic_*.xml` vector drawings have centred path bounds. `tests/controls_icon_geometry.py` checks the actual vector paths; `tests/device_controls.py` checks focused button/image/text bounds on-device.
4. Native Fire TV settings caused low-memory reclamation of the background `:home` process during extended testing. The recreated control screen lost focus/background and Settings lost its page. Saved activity state now retains the control/page/focus/scroll position; `ControlBackdrop.java` persists the existing tiny blurred bitmaps so reopening retains a fullscreen blur even if the Home activity is gone.

5. Deeper native destination checks found that Bluetooth fell back to the unrelated About page, while Display opened an unsupported resolver. Fire OS has no handler for Android's Bluetooth/HDMI/Dream intents, and Display/Audio handlers require an Amazon signature permission. `FireTv.java` now centralises routes: native Remotes & Bluetooth Devices for Bluetooth, actual settings grid with explicit guidance for protected/absent pages, and a clear ADB-setup explanation for unavailable notification-access UI. Both controls and full Settings use this route. `tests/device_native_settings.py` validates the actual destination and fresh UI text, not merely that another activity opened.

## Other requested work

`Profile.java` ports the original tvOS emoji/gradient avatar renderer into the hybrid Settings page with name editing and a system photo picker. Bitmap avatars are not icon-tinted. Profile refresh and horizontal navigation preserve focus. Long row values are width-bounded and ellipsised.

The original dock layout and protected screensaver/background/weather source files were preserved. Local before/after source hashes are checked separately. The upstream movie/photo screensaver remains distinct from manual StandBy.

## Verification

See [VERIFICATION.md](VERIFICATION.md) for final device results, measured performance and limitations. The original StandBy regression failed before the focus fixes and passed afterwards. Recorded gear/Menu opening frames before and after demonstrate removal of the scaled fullscreen rectangle; personal recordings remain outside Git.

## Scope

This changes the Android launcher app, not Fire OS firmware. Full account viewing history depends on metadata published by streaming apps. The public APK deliberately contains no personal catalogue keys. Optional TMDB movie artwork is not enabled by a shared key.
